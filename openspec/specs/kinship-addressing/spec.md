# kinship-addressing Specification

## Purpose

定义亲属称谓里**排行前缀**（大姨 / 二姨 / 三叔 / 小姑）与**「小」化**的判定口径：序位从哪一段序列里算、参照长辈是否占号、「小」的候选池有多大、拿什么当年龄证据。

## Requirements

### Requirement: 女性主体的排行序位从祖辈女儿序列计算

排行主体为女性时，系统 SHALL 以「该女性在其祖辈的女儿序列中、按排行值升序的位置」作为排行序号（0 → 大，1 → 二，依此类推）；序列**包含参照长辈本人**（妈妈自己就是祖辈的女儿，占她那一格），但她从我这儿不叫「姨」而叫「妈妈」。

#### Scenario: 妈妈是长女
- **WHEN** 妈妈是长女（排行 0），两个妹妹排行 5 与 6
- **THEN** 排行 5 的妹妹序位为 1 → 二姨；排行 6 的妹妹序位为 2 → 三姨（未触发「小」化时）

#### Scenario: 妈妈排行老二
- **WHEN** 妈妈排行 1，姐姐排行 0，两个妹妹排行 2 与 3
- **THEN** 姐姐 → 大姨；排行 2 的妹妹 → 三姨；排行 3 的妹妹 → 四姨

#### Scenario: 从妹妹的孩子的视角看妈妈
- **WHEN** 视角人物是排行 5 那位妹妹的孩子，目标是妈妈（排行 0）
- **THEN** 妈妈序位为 0 → 大姨

### Requirement: 男性主体的排行沿用「所见即所得」

排行主体为男性时，系统 SHALL 直接采用其排行值作为序号，**不在同性序列里重数**，断号照报。此条为既有口径，本次不变，用于锁定边界：妈妈是女儿，进不了儿子序列，因此不影响舅舅的排行。

#### Scenario: 兄弟间夹着姐妹
- **WHEN** 外公家六个孩子排行 0..5，兄弟分别排行 0 / 1 / 3 / 5
- **THEN** 分别叫 大舅 / 二舅 / 四舅 / 六舅，不因夹在中间的姐妹与妈妈跳号

### Requirement: 「小」化的候选池是参照长辈的全体同胞

判断某人是否叫「小X」时，系统 SHALL 以「参照长辈（父亲或母亲）的**全体同胞，不限性别**」为候选池，只取**比参照长辈排行值更大、且在池中排行值最大**的那一个；排在后面的照报排行。叔姑侧与岳家侧（妻子的娘家、丈夫的娘家）同口径，不分类别。

#### Scenario: 最小的那位是舅舅
- **WHEN** 妈妈排行 2，同胞排行 3 / 4 / 5 分别是二姨、三姨、小舅
- **THEN** 小舅 → 小舅；二姨 → 二姨、三姨 → 三姨（都照报排行）

#### Scenario: 最小的那位是姑姑
- **WHEN** 爸爸排行 1，叔叔排行 2 / 3，姑姑排行 4 / 5 / 6，其中排行 6 最小
- **THEN** 排行 6 的姑姑 → 小姑；三位叔叔照报排行

#### Scenario: 岳家同口径
- **WHEN** 视角人物的女性配偶排行 1，其舅舅排行 4、其阿姨排行 5
- **THEN** 排行 5 的阿姨 → 小姨

#### Scenario: 跨家庭不入池
- **WHEN** 奶奶家有四个儿子，外公家有三个女儿
- **THEN** 奶奶家最小的儿子叫小叔；外公家最小的女儿叫小姨；两边的判定互不影响

### Requirement: 「小」化只以排行值为年龄证据

系统 SHALL 只用排行值判断长幼与年幼，不再读取出生年参与「小」化判定；排行值缺失（未填）时无法比较大小，SHALL 退回照报排行。断号（如 0 / 2 / 5）按记录中最后一个计算。

#### Scenario: 全员没有出生年
- **WHEN** 同一辈的所有人出生年均为空，但排行值齐全
- **THEN** 仍然按排行值判定出「小X」，而不是一律照报排行

#### Scenario: 排行断号
- **WHEN** 同辈排行值为 0 / 2 / 5
- **THEN** 排行 5 的那位是池中最大 → 叫「小X」

#### Scenario: 排行值缺失
- **WHEN** 池中有人排行值为空
- **THEN** 判不出谁最小 → 全体照报排行，不出现「小X」

### Requirement: 「小」化覆盖排行前缀

系统 SHALL 先算出排行前缀，再判定是否「小」化；「小」化成立时用「小X」取代排行前缀（大姨 / 二姨 / 三姨 一律让位于 小姨）。称谓对象为女性亲属的丈夫时，配偶称呼同样让位（姨夫 / 妗子 / 婶 / 姑父）。

#### Scenario: 序位与最小重叠
- **WHEN** 某人序位算出「三姨」，同时是妈妈同胞中排行值最大的
- **THEN** 叫 小姨

#### Scenario: 配偶跟着让位
- **WHEN** 被小化的分别是舅舅、阿姨、叔叔、姑姑
- **THEN** 他们的配偶分别叫 妗子 / 姨夫 / 婶 / 姑父，均不加「小」也不报排行

### Requirement: 比我爸妈年长的那一位不叫「小」

当排行主体的排行值小于参照长辈（辈分上比我爸妈大）时，系统 SHALL 照报排行，不得使用「小X」。

#### Scenario: 实际是伯伯却排行最末
- **WHEN** 爸爸排行 3，叔叔排行 0 / 1 / 2（排行 0 是大哥，排行 2 最小）
- **THEN** 排行 2 的那位叫 二伯，排行 0 的那位叫 大伯；池中没有小叔

### Requirement: 排行称呼与视角无关

同一个人被同一辈的不同视角人物称呼时，其排行前缀 SHALL 一致；差异只来自该人是否为视角人物的参照长辈（是则称「妈妈」/「爸爸」）。

#### Scenario: 两个侄辈看同一位姨
- **WHEN** 长女的孩子与二女的孩子分别看向排行 5 的那位姨
- **THEN** 两边都叫 二姨，不会一个叫大姨、另一个叫二姨
