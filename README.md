# 族谱软件 · PC 桌面版

不常回家、亲戚认不全、过年叫不出称呼 —— 这个软件解决的就是这件事。

核心**不是记录，是称谓自动推导**：只录「谁是谁的爸妈」「谁和谁是夫妻」，称呼实时算出来。
改一处关系，全树称谓自动更新。数据只存在你自己硬盘上，不联网、不上传。

> 本目录于 2026-09-18 从 `D:\workbuddy\2026-09-17-16-17-59\` 迁出，独立成项目。

---

## 目录结构

| 目录 / 文件 | 内容 |
|---|---|
| `app/` | **代码本体**（Electron 工程）。完整说明见 [`app/README.md`](app/README.md) |
| `文档/` | 项目总览 · 代码审查报告 |
| `数据底稿/` | CSV 录入模板（`people.csv` / `relationships.csv` + 字段说明） |
| `数据/` | **运行时数据目录** —— `genogram.db` 主库 + `.bak` + `backups/` 每日快照 + `photos/` |
| `dist/` | 打包产物（安装版 / 免安装版 exe + `win-unpacked/`） |

数据目录**刻意放在 `app/` 之外** —— 卸载、重装、删代码都不会丢数据。
（备份 = 直接拷走整个 `数据/` 文件夹。）

---

## 常用命令

```bash
cd app

npm start              # 启动桌面应用
npm test               # core(94) + 存储(37) 单测，纯 Node，秒级
npm run test:e2e       # 桌面版端到端（真 Electron）
npm run db:inspect     # 不启动应用，直接查数据/里那个库有什么
npm run dist           # 打 Windows 安装包 + 免安装版 → D:\族谱pc端项目\dist\

npm run web            # 网页版调试（http://127.0.0.1:5173），存储退回 localStorage
```

**换数据目录**：设环境变量 `GENOGRAM_DATA_DIR`，例如 `GENOGRAM_DATA_DIR=E:\我的族谱 npm start`。
