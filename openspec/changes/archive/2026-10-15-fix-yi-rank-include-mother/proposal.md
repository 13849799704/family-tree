# Proposal

## Why

用户本机真实数据（`数据\books\book-mv247k0n-bo0l`，外婆家七个孩子 `order_no` 0..6，妈妈李书敏 `order_no=4` 是长女，两个妹妹李书香 5、李书菊 6）里，妈妈的排行被算错了：

```
刘东伟 -> 李书香    大姨     ← 应为 二姨
刘东伟 -> 李书菊    二姨     ← 应为 小姨
王寄林 -> 李书敏    大姨     ← 正确（妈妈在菊那边是长女，占第一位）
```

同一个李书敏，在自己孩子这边是「排行第 0 位」，在妹妹的孩子那边是「第 0 位」——排行随视角漂移：两个不同的姨会被各自的侄辈同时叫成「大姨」。根因是 `kinship.js` 里那条「姐妹行把锚点剔出序列」的规则本为「我的姐妹」而写，却被无差别套到 `M Z` / `F Z`，把**妈妈本人**从女儿的序列里剔掉了，于是排行整体前移一位。

用户裁定：**妈妈依旧参与排行**。妈妈在姐妹中排第几，她的孩子和其他姐妹的孩子都按这个数喊人；排行算完之后，若该人同时是爸妈同胞里最年幼的那一个，则叫「小X」（小化盖住排行）。

顺带暴露第二个障碍：「小」化判定只认出生年，而用户这本谱 178 人里只有 2 人填了出生年 —— 规则在这份数据上从未生效过。用户裁定：**排行（`order`）就是年龄证据**，因为修家谱的人知道排行而不知道年龄，且存在辈分大年龄小的人。

## What Changes

- **BREAKING** —— 姨的排行改为「妈妈占号」：排行 = 该女性在祖辈**女儿序列**（含妈妈本人）里的序位。妈妈自己占一格，只是不从我这儿叫「姨」。适用于 `M Z` / `F Z` / `W M Z` / `H M Z`。此裁定**推翻 2026-10-11 的「妈妈占的那个号不该让姨妈跟着跳」**。
- **BREAKING** —— 「小」化的候选池从「同性别同胞」扩到「爸妈的全体同胞（不限性别）」：最小的那一个才叫「小X」，排在它前面的照报排行。叔姑侧（`F B` / `F Z`）与岳家侧（`W M B` / `W M Z` / `W F B` / `W F Z` / `H M ...`）同口径，**不分类别**。
- **BREAKING** —— 「小」化判定只比 `order`，出生年不再参与。断号（0/2/5）按记录里最后一个算；`order` 整格为空则判不出大小，退回照报排行。
- 纠正 `rules.js` 的 JSDoc：现写着「排行第 4 位起才用小化」，这条门槛用户 2026-10-10 已否掉，注释是错的。
- 纠正 `kinship.js` 中「锚点 = 主语的父亲」的注释：实际取的是路径上主语的前一个人，对 `M Z` 而言是**妈妈**而非外婆。
- 更新 `app/tests/run.js` 的断言：`:815`（母系旁支）、`:863`（女性重数）、`:988`（`u5` 无出生年不许叫小）、`:1024`（宽家庭）四条用例按新口径重写。

**不动**：舅舅一侧（妈妈是女儿，进不了儿子序列，仍走男性「所见即所得」直取 `order`）；长幼判定本身（伯/叔、大舅子/小姨子的选词）仍以出生年优先——用户同意留到下一次再议。

## Capabilities

### New Capabilities

- `kinship-addressing`: 亲属称谓的**排行前缀**与**「小」化**口径 —— 序位从哪算、参照长辈是否占号、「小」的候选池有多大、拿什么当年龄证据。

### Modified Capabilities

（无 —— 项目现有 spec 只有 `person-search` / `topbar-layout` / `ui-icon-sizing`，都与称谓无关。）

## Impact

- `app/src/core/kinship.js`：`sibGroup`（剔除条件收窄）、`rankAmongSibs`、`isYoungestSmaller`（候选池与判定改写）、`finalize` 内注释
- `app/src/core/rules.js`：`Rule` 类型 JSDoc 中关于 `small` 的错误描述
- `app/tests/run.js`：四条断言 + 现有用例的期望值
- 无新依赖、无 API 变更、无数据迁移
- 本机验收基准（`我的家族` 谱，视角=刘东伟）：李书香 = **二姨**、李书菊 = **小姨**、王寄林/王寄阳 → 李书敏 = **大姨**、王寄林 → 李书香 = **二姨**
- 已知代价（用户确认接受）：① 舅舅排在最末时，姨一个都叫不到「小」；② 叔叔与姑姑抢同一个「小」，最小者是姑就没人叫小叔；③ 姐妹极多时会出现「五姨」（那是实打实的女儿序，不是把舅舅的号算进去）
